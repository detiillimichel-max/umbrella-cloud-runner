☁️ Umbrella Cloud Runner
Um endless runner fofo inspirado no Dino do Chrome, mas com uma nuvenzinha de guarda-chuva amarelo desviando de pássaros e tempestades!

🎮 Demo ao vivo: 

Game Preview HTML5 GitHub Pages

📸 Inspiração
Baseado no jogo da sua screenshot - céu azul degradê, nuvem protagonista com guarda-chuva amarelo, pássaros pretos e nuvens de raio.

🕹️ Como Jogar
Toque / Clique / Espaço / Seta ↑ / W = voar pra cima
Segure = voo contínuo
Desvie dos obstáculos que vêm da direita
A velocidade aumenta com a pontuação, igual ao Dino do Chrome!
✨ Features
Física estilo Flappy Bird com gravidade e impulso
3 tipos de obstáculos: Pássaro Preto, Pássaro Pega e Nuvem de Tempestade
Parallax com 3 camadas de nuvens
Score com 6 dígitos (000000)
Best Score salvo no navegador
100% responsivo e mobile-first
Sem dependências, tudo em um único index.html
🚀 Como rodar local
bash
# Só abrir o arquivo
open index.html
📦 Como publicar no GitHub Pages
Opção 1 - Pelo navegador (mais fácil)
Crie um repositório novo no GitHub com o nome umbrella-cloud-runner
Faça upload do arquivo do jogo renomeado para index.html
Faça upload deste README.md
Vá em Settings > Pages
Em Build and deployment > Source selecione Deploy from a branch
Branch: main / pasta: / (root) > Save
Em 1-2 minutos seu jogo estará em https://SEU_USUARIO.github.io/umbrella-cloud-runner/
Opção 2 - Por linha de comando
bash
git init
git add index.html README.md
git commit -m "feat: jogo inicial nuvem voadora"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/umbrella-cloud-runner.git
git push -u origin main
# Depois ative o Pages nas Settings
